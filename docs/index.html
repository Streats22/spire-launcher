What Spire does

One job per profile: isolate userdata, install content, launch cleanly.

  • Isolated instances Separate mods, saves, prefabs, and logs — verified at every launch.
  • Official auth & client Sign in with Hytale OAuth; point at an install or fetch builds through Spire.
  • Mods from the places you already use CurseForge, Nexus, Thunderstore, Modtale / Modifold, Modrinth-ready.
  • Share with .spirepack Export mods and profile settings; optionally include world saves.

Local-first by design

Spire is an app on your machine. No Spire accounts, no cloud sync, no telemetry.

Stays on disk
Profiles, keys, mods, and tokens live under your Spire data folder.
Talks only when you ask
CurseForge, Nexus, or Hytale APIs fire only for features you use.
Optional updates
A public JSON check — no identity — and you can turn it off.
