Privacy Policy

Spire Launcher (“Spire”) is a local desktop app. This policy explains what stays on your computer, when Spire uses the network, and what we (the project maintainers) do not collect.

Effective: 30 July 2026 · Applies to the Spire desktop app and this project site (streats22.github.io/spire-launcher).

Summary Who we are Local data Network Third parties Website Children Your choices Changes Contact

Summary

  • No Spire account We do not create accounts, profiles, or cloud backups for Spire itself.
  • No telemetry Spire does not ship analytics SDKs or phone-home usage tracking.
  • Your machine holds the data Instances, mods, worlds, settings, API keys, and Hytale tokens live in your OS app-data folder.
  • Network only for features you use Plus an optional anonymous update check you can turn off.

Who we are

Spire is an open-source project maintained by streats22 (streatsdesign). Spire is not affiliated with Hypixel Studios, Riot Games, or Prism Launcher.

This policy covers the Spire application distributed via GitHub Releases and the static project pages hosted on GitHub Pages.

Data stored on your device

Spire stores data locally under your operating system’s application data folder, for example:

  • Windows: %APPDATA%\Spire
  • macOS: ~/Library/Application Support/Spire
  • Linux: ~/.config/Spire

Depending on what you use, that may include:

  • Instance / profile metadata, groups, notes, icons, and Java args
  • Mods, prefabs, worlds, servers lists, and run logs for each instance
  • App settings (theme, layout, update preferences, store API keys you enter)
  • Hytale account tokens and profile selection from official sign-in (device flow)
  • Optional game client packages downloaded through Spire’s Install flow

We do not receive a copy of this folder. You can delete Spire’s local data from Settings (clear credentials or wipe Spire data) or by removing the folder yourself. Uninstalling the app may leave the data folder until you remove it.

When Spire uses the network

Optional Spire update check

If update checks are enabled (Settings → General), Spire may request a public JSON manifest (by default updates/latest.json on this GitHub repository). That request is anonymous: Spire does not attach your name, Hytale account, or a Spire user id. You can disable the check at any time.

Installed Setup builds may also use GitHub Releases metadata (latest.yml / blockmaps) to download an update when you choose to. Portable and development builds typically open the release page in your browser instead.

Features you trigger

Spire may contact third-party services only when you use related features, for example:

  • Signing in with Hytale / listing or downloading official client builds
  • Searching or installing content from CurseForge, Nexus Mods, Thunderstore, Modtale, Modifold, or Modrinth
  • Opening a project page, browser download, or other URL you choose

Those services process data under their own privacy policies. Spire sends what those APIs require for the action you started (for example an API key you stored locally, or OAuth tokens for Hytale sign-in).

Third parties

Spire does not sell personal data. Relevant third parties include:

  • Hypixel / Hytale — authentication and official game/client services when you sign in or download through Spire
  • Mod platforms — CurseForge, Nexus Mods, Thunderstore, and others you browse or install from
  • GitHub — source code, Releases downloads, optional update manifests, and hosting for this site (GitHub Pages)

If you import or export a .spirepack, that file is created or read on your machine (or wherever you choose to share it). Spire does not upload packs to a Spire cloud.

This website

The project site is static HTML on GitHub Pages. We do not run a Spire account system or first-party analytics on these pages. GitHub (as the host) may process standard server or CDN logs according to GitHub’s privacy statement.

Pages may load fonts from Google Fonts. That can involve a network request to Google when you view the site; see Google’s privacy documentation for that service.

Children

Spire is a tool for managing a game you obtain through official channels. It is not directed at children under 13 (or the equivalent minimum age in your country). We do not knowingly collect personal information from children through Spire accounts, because Spire has none.

Your choices

  • Turn off Spire update checks in Settings → General
  • Avoid signing in or using mod stores if you do not want those network calls
  • Remove saved API keys or Hytale accounts from Settings / Accounts
  • Clear Spire’s local data from Settings → Data, or delete the Spire data folder
  • Build Spire from source and audit or modify network behavior yourself

Changes to this policy

We may update this page when Spire’s behavior or hosting changes. The “Effective” date at the top will change when we do. Continued use of Spire after an update means you accept the revised policy for future use.

Contact

Questions about privacy: open an issue on github.com/Streats22/spire-launcher or contact the maintainer via GitHub (@Streats22).
