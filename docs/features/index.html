Spire Launcher features

Spire is a cross-platform Hytale instance launcher: separate profiles, content browsers, and a clean launch path — without redistributing the game.

  • Isolated instances Create, rename, duplicate, and group profiles. Each instance keeps its own mods, userdata, prefabs, and logs. Isolation is repaired at launch.
  • Launch & auth Sign in with official Hytale OAuth, use multiple accounts, pick a game profile, and launch with per-instance userdata and mods dirs.
  • Game install Use an existing official Hytale install, or download and manage client builds through Spire’s Install / Versions UI.
  • Mods & content Browse and install from CurseForge, Nexus Mods, Thunderstore, Modtale / Modifold, and Modrinth-ready plumbing. Prefabs, worlds, bootstraps, and translations too.
  • Worlds Manage saves under userdata, create with Adventure / Creative / Flat presets, apply mod sets, and download world packs when the source allows.
  • .spirepack sharing Export mods and profile settings as a .spirepack; optionally include world saves for friends or backups.
  • Local-first privacy No Spire accounts, no cloud sync, no telemetry. Optional update checks are anonymous and can be disabled.
