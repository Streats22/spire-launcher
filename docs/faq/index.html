Spire Launcher FAQ

Common questions about the Spire Hytale launcher — what it is, how to get it, and how privacy works.

What is Spire Launcher?

Spire Launcher (often just Spire) is a free, open-source Hytale instance launcher for Windows, macOS, and Linux. It keeps profiles, mods, and worlds isolated — a Prism-style workflow for Hytale — without redistributing the game itself.

Does Spire redistribute Hytale?

No. Installers from GitHub do not include the Hytale client. You buy the game through official channels; Spire signs in with official auth and manages instances around your install.

Is Spire affiliated with Hypixel or Riot?

No. Spire is a third-party community project. It is not affiliated with Hypixel Studios, Riot Games, or Prism Launcher.

Where do I download Spire Launcher?

Get the latest build from GitHub Releases or the download page. Windows (setup + portable), macOS DMG, and Linux AppImage / deb / tar.gz are published there.

Does Spire collect telemetry or need a Spire account?

No Spire accounts, no cloud sync, no telemetry. Data stays in your OS app-data folder. Optional update checks hit a public JSON with no identity and can be turned off.

Can Spire install Hytale mods?

Yes — CurseForge, Nexus Mods, Thunderstore, Modtale / Modifold, Modrinth-ready support, file import, download-folder watch, and .spirepack share/import. See features for the full list.
