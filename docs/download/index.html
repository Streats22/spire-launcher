Download Spire Launcher

Free installers for Windows, macOS, and Linux. Spire is an open-source Hytale launcher for isolated profiles, mods, and worlds.

Latest release on GitHub See features

Choose your platform

  • Windows

    Setup wizard (Spire-Setup-*.exe) or portable Spire *.exe.

  • macOS

    Open the DMG and drag Spire into Applications.

  • Linux

    AppImage, .deb, or portable .tar.gz from Releases.

Spire does not ship the Hytale client. You need a legitimate Hytale purchase; Spire signs in through official auth and manages instances around your install.

After you install

  1. Open Spire and sign in with your Hytale account.
  2. Point at an existing install or download a client build in Install / Versions.
  3. Create an instance, add mods, then launch.

More detail in the quick start on GitHub or the FAQ.
