Spire / Hytale launcher

Hytale launcher with instances — Spire

If you searched for a Hytale launcher that can keep mods and saves apart per profile, Spire Launcher is built for that job.

Spire is a cross-platform Hytale instance launcher for Windows, macOS, and Linux. It takes a Prism Launcher–style approach: isolated profiles, separate mods and userdata per instance, content browsers, and a clean launch flow.

Spire is not the official Hytale Launcher from Hypixel Studios. It is a third-party, open-source tool. You still own the game through official channels — Spire does not redistribute the Hytale client.

Why people use Spire as a Hytale launcher

  • Multiple instances without mixing mods and worlds
  • Install content from CurseForge, Nexus, Thunderstore, and community catalogs
  • Share setups with .spirepack
  • Local-first: no Spire accounts, no telemetry
