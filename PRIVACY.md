# Spire Launcher Privacy Policy

**Effective: 30 July 2026**

The canonical version is published on the project site:

**https://streats22.github.io/spire-launcher/privacy/**

## Summary

- No Spire accounts, cloud sync, or telemetry
- Profiles, tokens, API keys, mods, and worlds stay in your OS app-data folder
- Network use is for features you trigger (Hytale auth, mod stores, optional update checks)
- Optional update check is an anonymous `GET` of a public JSON manifest and can be disabled

For full detail (local paths, third parties, website hosting, contact), see the [privacy page](https://streats22.github.io/spire-launcher/privacy/).
